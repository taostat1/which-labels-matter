# Controlled simulation

Each of 16 configurations contains 100 independent pools and one path per method per pool. The ten methods therefore contribute 16,000 paths to `../paths.csv.gz`. The manuscript reporter audits the decisions and coverage and builds Tables 1 and 8 from these records.

Each pool contains 2,048 objects with four attributes. The original generator draws two Rademacher feature vectors, four correlated latent label uniforms per object, 16 random training and validation splits of size 64 each, and a final training subset of 64 objects. The seed for pool index `i` is the family seed plus `100*i`. The main experiment uses family seed 202611060701 for penalties .25, .5 and 2. The earlier weak-penalty experiment uses 202611010101 for penalty .125. Pool identity is shared across the methods and configurations within each family. In the original schedule the weak-penalty experiment used a larger grid, so its path seeds retain the original cell index.

Each method buys labels through its own cache. The acquisition tolerance is .01 and the error probability is .05. LEC checks its public range, then counts positive contributions cumulatively and checks a Clopper-Pearson interval at 128 through 32768 draws by powers of two. Uniform sampling uses an empirical Bernstein interval for its unequal-size contributions. The fixed-bound ablation retains LEC’s initial approximation bound at every inspection and uses the same cumulative CP interval, early stopping, and exact fallback. Separate bounds substitute per-candidate approximation bounds at entry and subsequent inspections. Whole-object purchases reveal all four attributes of each queried object. No early stopping runs all nine inspections, suppresses returns at the public check and intermediate inspections, and preserves eligible cache-bound refinements. It decides at 32768 draws or completes exact CV if still unresolved.
